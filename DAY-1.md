# ZERO TO HERO – 10 Day Interview Drill (Fresher)
## DAY 1
---

## 1. Programming Foundations + OOPS

**Q1. What is programming?**  
Programming is writing instructions that tell a computer how to perform tasks and solve problems.

**Q2. What is OOPS?**  
OOPS is a programming approach based on objects. It helps organize code using real-world concepts like classes and objects.

**Q3. What is a class and an object?**  
A class is a blueprint.  
An object is an instance of that class.

**Q4. What is inheritance?**  
Inheritance allows one class to acquire properties and methods of another class to reuse code.

**Q5. What is polymorphism?**  
Polymorphism allows the same method name to behave differently based on the object.

---

## 2. Java Basics

**Q1. What is Java?**  
Java is a high-level, object-oriented, platform-independent programming language.

**Q2. Why is Java platform independent?**  
Java compiles code into bytecode, which runs on the JVM instead of directly on the operating system.

**Q3. What is JVM?**  
JVM executes Java bytecode and manages memory.

**Q4. What are access modifiers?**  
They control visibility of variables and methods: public, private, protected, and default.

**Q5. Difference between `==` and `equals()`?**  
`==` compares references.  
`equals()` compares actual values.

---

## 3. JavaScript Fundamentals

**Q1. What is JavaScript?**  
JavaScript is a scripting language used to make web pages interactive.

**Q2. Difference between var, let, and const?**  
var is function scoped.  
let and const are block scoped.  
const cannot be reassigned.

**Q3. What is hoisting?**  
JavaScript moves variable and function declarations to the top during execution.

**Q4. What are arrow functions?**  
They provide a shorter syntax for functions and better handling of `this`.

**Q5. What is a closure?**  
A function that remembers variables from its outer scope even after execution.

---

## 4. ReactJS (Primary Focus)

**Q1. What is React?**  
React is a JavaScript library for building fast and reusable UI components.

**Q2. What is JSX?**  
JSX allows writing HTML-like code inside JavaScript.

**Q3. Difference between props and state?**  
Props are read-only and passed to components.  
State is managed inside a component and can change.

**Q4. What is useEffect?**  
It handles side effects like API calls and lifecycle events.

**Q5. Why is React fast?**  
Because of the Virtual DOM, which updates only changed components.

---

## 5. Backend Basics (Node.js + Express)

**Q1. What is Node.js?**  
Node.js is a runtime that allows JavaScript to run on the server.

**Q2. What is Express.js?**  
Express is a Node.js framework used to build APIs and web servers.

**Q3. What is middleware?**  
Middleware is a function that runs between request and response.

**Q4. What is routing?**  
Routing defines how URLs are handled by the server.

**Q5. Why use Node.js?**  
It is fast, scalable, and uses non-blocking I/O.

---

## 6. APIs

**Q1. What is an API?**  
An API allows different applications to communicate with each other.

**Q2. What is a REST API?**  
A REST API follows HTTP methods to perform CRUD operations.

**Q3. What are HTTP methods?**  
GET, POST, PUT, DELETE.

**Q4. What is JSON?**  
JSON is a lightweight data format used to exchange data.

**Q5. What does HTTP status code 404 mean?**  
It means the requested resource was not found.

---

## 7. Databases (SQL + NoSQL)

**Q1. What is a database?**  
A database stores and manages structured data.

**Q2. Difference between SQL and NoSQL?**  
SQL uses tables with fixed schema.  
NoSQL uses collections with flexible schema.

**Q3. What is a primary key?**  
A unique identifier for each record in a table.

**Q4. What is a foreign key?**  
A key that links two tables together.

**Q5. Why is MongoDB used?**  
It is flexible, scalable, and works well with JSON data.

---

## 8. Flutter & Dart Basics

**Q1. What is Flutter?**  
Flutter is a framework for building cross-platform apps using one codebase.

**Q2. What is Dart?**  
Dart is the programming language used in Flutter.

**Q3. What is a widget?**  
Everything in Flutter is a widget, including UI elements.

**Q4. Stateless vs Stateful widget?**  
Stateless widgets do not change UI.  
Stateful widgets update UI dynamically.

**Q5. Why is Flutter popular?**  
Fast development, single codebase, and high performance.

---

## 9. Bootstrap + UI Concepts

**Q1. What is Bootstrap?**  
Bootstrap is a CSS framework for building responsive designs.

**Q2. What is responsive design?**  
Design that adapts to different screen sizes.

**Q3. What is the Bootstrap grid system?**  
A 12-column layout system for responsive layouts.

**Q4. What are components in Bootstrap?**  
Prebuilt UI elements like navbar, buttons, and cards.

**Q5. Why use Bootstrap?**  
It saves development time and ensures UI consistency.
